About Educational Assistance Policies

These policies define the global rules that apply to all educational assistance programs in the institution. You can set the maximum number of assistances a student can hold, per-category limits, and combination rules.

1. Global Assistance Limit

Enabled

Set the maximum number of active educational assistance programs a student can have across all categories.

Set to 0 for unlimited assistance.

2. Per Category Limits

Set the maximum number of active educational assistance programs allowed per category.
